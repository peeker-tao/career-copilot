## 一、本周重点工作

### 1. 面试模块深度开发 🔥
| 事项 | 说明 |
|------|------|
| **WebSocket 流式对话** | 引入 Socket.IO，实现 AI 面试官实时流式消息推送，替代原有的 setTimeout 伪打字机效果；支持自动重连、JWT 鉴权、连接状态指示 |
| **AI 面试官动画头像** | 纯 CSS 动画头像组件，支持 idle（呼吸眨眼）/ speaking（开口说话）/ listening（倾听）/ finished（结束）四种状态，提升面试沉浸感 |
| **语音输入框架** | 搭建语音功能骨架（api + hooks + store + types），按项目现有 Mock 模式设计，预留 Azure Speech Services 集成接口，支持录音、状态管理、自动发送 |
| **面试关联简历** | 创建面试时可选择关联已完成的简历，支持下拉选择器和技能预览 |
| **面试报告自动生成** | 面试结束后自动触发报告生成，防止用户重复点击导致重复请求 |
| **MySQL 日期兼容** | 修复后端 MySQL datetime 字符串浏览器无法解析的兼容性问题 |
