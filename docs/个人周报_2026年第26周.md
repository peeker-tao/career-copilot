## 三、项目实践遇到的问题

| 问题 | 具体现象 | 解决过程与思考 |
|------|---------|--------------|
| **后端API响应格式不统一** | 简历列表一直显示"暂无数据"，实际后端有返回 | 通过DevTools发现数据在response.data.items而非list。进一步检查发现不同端点返回格式各异（直接数组/{items}/{list}）。写通用unwrapData函数按优先级尝试，在Axios拦截器统一处理。**反思**：项目初期应定好API响应规范（如统一{code,data,message}格式），避免前端适配多种格式 |
| **MySQL datetime导致页面崩溃** | 面试计时器显示Invalid Date，消息时间戳空白 | 定位到new Date("2026-06-27 10:00:00")在Safari返回Invalid Date，JS Date只认ISO 8601。写safeFormatTime函数：空格→T+时区偏移，解析失败返回空字符串，保证不崩溃。**反思**：跨平台数据交换应用ISO 8601标准格式，前端需对所有外部数据做defensive parsing |
| **WebSocket切页后断连不恢复** | 用户从面试室切到其他页面再回来，连接断开 | 发现原因：React组件卸载时disconnect()但重新挂载时没reconnect。解决方案：useEffect清理只断开不销毁 + connection状态实时显示 + token刷新后重建socket + connect_error捕获提示重新登录。**反思**：WebSocket生命周期需对齐React组件生命周期，考虑unmount/reconnect/token刷新全场景 |
| **面试报告重复生成** | 快速点击"结束面试"多次，生成多份报告 | 按钮onClick没做防抖，异步请求在第一次完成前重复发起。加isGeneratingReport状态锁 + 按钮disabled + loading状态，双重保险。**反思**：所有异步操作按钮都应考虑防重复提交，这是前端通用模式 |
| **ECharts雷达图tooltip不符合需求** | 悬停显示所有维度数据，需求是只显示最近顶点 | 查看ECharts文档发现radar tooltip可用formatter回调定制。遍历params.value和indicators找到最大值索引作为最近顶点，只展示该维度。**反思**：善用formatter回调可解决大部分ECharts定制化需求，多查官方示例 |
| **首次面试消息角色渲染错误** | 第一条AI消息显示在用户气泡里 | 后端发role为assistant的消息，但前端只识别user和ai两种role。在MessageRole类型补充assistant后修复。**反思**：前后端角色枚举值需要对齐，TypeScript联合类型可以避免这类问题 |
