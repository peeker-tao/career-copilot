## 一、认证与用户管理

### 功能概述

- **注册**：邮箱+密码注册，bcrypt 加密存储，注册即返回 JWT 令牌对
- **登录**：校验凭据，返回 access_token（7 天有效）+ refresh_token（30 天有效）
- **令牌刷新**：refresh_token 换新 access_token，无需频繁登录
- **个人资料**：查看和修改姓名、头像、教育背景、目标职位
- **模型配置**：用户可自定义偏好的 AI 模型参数
- **修改密码**：需提供旧密码验证
- **忘记密码**：邮箱接收 6 位验证码（10 分钟有效），验证后重置密码
- **用户列表**：查看平台所有用户（管理员功能）

### 实现细节

- 采用 **Passport.js** 策略模式，`JwtStrategy` 从请求头 Bearer Token 解析身份，`JwtRefreshStrategy` 从请求体读取 refresh_token
- 自定义 `RolesGuard` 实现角色授权，`@Roles('admin')` 装饰器标注管理员接口
- 密码使用 **bcrypt 10 轮** 哈希，响应中全局脱敏 `passwordHash` 字段
- **双层限流**：登录 10 次/秒，注册 5 次/秒，验证码 3 次/秒，防止暴力破解
- 密码重置走完整邮件链路：SMTP（QQ 邮箱）→ 6 位纯数字验证码 → 服务端校验

## 二、简历系统

### 功能概述

- **简历上传**：支持 PDF、DOCX 格式，≤10MB，上传后自动解析
- **简历解析**：AI 提取简历中的个人信息、技能树、工作经历、教育背景、项目经验
- **简历列表**：分页展示，支持按解析状态筛选
- **简历详情**：查看单份简历的结构化信息
- **简历删除**：删除数据库记录的同时清理本地文件
- **简历改写**：AI 对指定章节生成改写建议，并支持一键替换
- **简历筛选基准**：批量导入 AI 筛选基准数据，支持从 CSV 文件填充

### 实现细节

- 文件解析采用 **双引擎**：PDF 使用 `pdf-parse`，文本不足 50 字符自动触发 OCR 回退（`tesseract.js`）；DOCX 使用 `mammoth`
- 解析结果通过 **LLM 结构化提取**，返回规范化字段
- 异步队列处理：上传后 `resume-parser` 队列异步解析，避免阻塞，支持 3 次自动重试
- 改写功能分两步：先 AI 生成各章节改写建议，再对用户选定的章节进行重写并保存
- 集成 **NER 命名实体识别** 服务（外部 Python 服务），提取人名、机构名、技能关键词，超时 15 秒可降级

## 三、AI 引擎

### 功能概述

AI 引擎是项目的智能中枢，为所有模块提供 AI 能力：

- **多 LLM 适配**：同时支持 OpenAI、通义千问（DashScope）、DeepSeek，自动检测可用 API Key
- **流式对话**：支持 Server-Sent Events 流式输出
- **RAG 知识库**：本地向量化存储 + 语义检索，增强 AI 回答的准确性
- **智能缓存**：基于内容哈希的 Redis 缓存，相同提问直接命中
- **本地 Embedding**：Python 子进程运行 BGE-Small-ZH 模型，无需外部 API

### 实现细节

- **LLM 工厂模式**：三个 `OpenAICompatibleProvider` 实例共用同一接口，分别对接 GPT、Qwen、DeepSeek，根据环境变量自动选择
- **内容寻址缓存**：对请求内容做 SHA256 哈希作为缓存键，不同场景不同有效期（简历解析 7 天、面试题 24 小时、评估 1 小时）
- **RAG 流水线**：文档 → Embedding 向量化 → Redis 存储（JSON + 向量 ZSET）→ 查询时余弦相似度 Top-K → 注入 system prompt
- **本地 Embedder**：通过 `child_process` 启动 Python Worker，JSON 行协议通信，请求/响应 ID 匹配，支持并发推理
- **Prompt 工程**：5 个场景专用 Prompt（简历解析、面试出题、面试评估、职业规划、市场洞察），分别定义角色和输出格式

## 四、AI 模拟面试

### 功能概述

- **创建面试**：选择岗位和简历，AI 自动生成第一道面试题
- **流式对话**：WebSocket 实时传输 AI 回答，打字机效果逐字呈现
- **智能评估**：每次回答后 AI 自动评分，并决定追问、下一题或结束
- **历史记录**：查看过往面试列表、详情和完整消息记录
- **面试报告**：多维度评估报告，异步生成，支持进度轮询
- **手动结束**：用户可随时终止面试
- **语音面试列表**：独立的语音面试历史入口

### 实现细节

- **WebSocket Gateway**（`/ws/interview/:id`）：JWT 令牌通过 query 参数认证，协议为 `user_answer` → `ai_message_chunk` / `ai_message_done`
- **智能路由**：`evaluateAndContinue()` 方法将回答送入 LLM 评估，返回 `followUp`（追问）、`nextQuestion`（下一题）或 `complete`（结束）三种指令
- **岗位归一化**：`normalizePosition()` 对用户输入的岗位做关键词匹配和中文检测，无法识别时默认回落为"软件开发工程师"
- **报告 7 维度**：专业能力、沟通表达、逻辑思维、应变能力、项目经验、团队协作、学习潜力，每项含评分和改进建议
- **异步报告生成**：`feedback-generator` 队列消费，对话记录不足 2 轮则自动丢弃
- **结果持久缓存**：报告生成后缓存到面试记录的 `overallFeedback` JSON 字段

## 五、语音面试

### 功能概述

- **语音识别（ASR）**：上传音频文件，识别为文字，支持 mp3/wav/ogg/webm/m4a/flac 格式
- **语音合成（TTS）**：输入文字，合成为语音音频，返回可播放的音频 URL

### 实现细节

- **双提供商架构**：DashScope（阿里云百炼）为首选，OpenAI 自动兜底
- **ASR 主流程**（DashScope 模式）：获取 OSS 临时上传凭证 → 上传音频到阿里云 OSS → 提交异步转写任务 → 轮询任务状态直至完成 → 提取转写文本
- **ASR 兜底**：DashScope 失败时切换 OpenAI Whisper-1 模型，直接上传音频文件识别
- **TTS 引擎**：DashScope 使用 CosyVoice v3（`cosyvoice-v3-flash`），支持 6 种不同发音人风格；OpenAI 兜底使用标准 TTS API
- **文件限制**：音频 ≤20MB，服务端校验格式和大小

## 六、职业规划

### 功能概述

- **创建规划**：填写目标岗位，AI 自动生成完整的职业发展规划
- **技能差距分析**：对比当前技能与目标岗位要求，找出差距
- **分阶段学习路线**：按阶段组织学习目标和推荐资源
- **进度追踪**：标记各阶段完成进度，自动计算平均完成率
- **市场洞察**：查询指定岗位的市场薪资、需求趋势、核心技能
- **规划管理**：查看所有规划、删除不再需要的规划

### 实现细节

- **AI 生成三步走**：差距分析 → 技能去重 → 阶段资源排列，将 AI 原始输出转化为数据库规范格式
- **市场洞察**：独立调用 LLM 生成薪资区间、需求热度、核心技能词云、经验年限分布
- **进度计算**：阶段级进度取平均值作为规划总进度
- **所有权隔离**：严格按 `userId` 过滤，用户只能看到自己的规划

## 七、岗位匹配

### 功能概述

- **岗位推荐**：基于简历信息，AI 推荐 5 个匹配岗位
- **匹配度分析**：对特定岗位进行深度匹配分析，含关键词匹配兜底
- **状态管理**：标记岗位为感兴趣、不感兴趣、已投递、已收藏
- **统计看板**：各状态岗位数量统计
- **岗位数据填充**：一键填充默认岗位数据

### 实现细节

- **数据库优先策略**：已有 ≥5 条推荐记录则直接返回数据库缓存，否则调用 AI 生成
- **AI 推荐结果**：包含岗位标题、公司、薪资范围、地点、推荐理由和匹配分数
- **匹配度双引擎**：AI 分析优先，LLM 调用失败时自动回退到关键词匹配算法
- **用户交互追踪**：用户修改状态后实时更新统计

## 八、面试题库

### 功能概述

- **题库浏览**：按岗位、难度、类型、标签、关键词筛选，支持分页
- **分类管理**：查看所有题目分类
- **题目详情**：查看题目完整内容和关联信息，自动累计查看次数
- **AI 智能出题**：指定岗位和技能标签，AI 生成题目并持久化到题库

### 实现细节

- **AI 生成的题目**标记 `source='ai_generated'`，与预设题目区分
- **使用计数**：每次查看详情 `usageCount` 自动 +1，可识别高频题目
- **筛选引擎**：支持多维度组合筛选，`position` / `difficulty` / `type` / `tags`（JSON 包含） / `search`（模糊匹配）

## 九、学习资源推荐

### 功能概述

- **资源浏览**：按分类、类型、难度、标签、关键词筛选
- **资源详情**：查看完整资源信息，自动累计查看次数
- **分类浏览**：获取所有资源分类
- **AI 推荐**：基于用户简历的技能差距，AI 推荐个性化学习资源

### 实现细节

- **AI 推荐流程**：从用户简历提取 Gap Skills → 数据库搜索匹配资源（标签 + 难度）→ 不足时 AI 生成 → 自动持久化到数据库
- **AI 生成标记**：AI 生成的资源标注 `aiGenerated=true`、`relevanceScore=5.0`
- **使用计数**：同题库模块，`usageCount` 自增追踪热度

## 十、管理后台

### 功能概述

- **数据看板**：展示用户、简历、面试、规划、资源总数及 7 天每日趋势
- **用户管理**：用户列表分页、搜索、编辑、删除
- **简历管理**：全平台简历查看和管理
- **面试管理**：面试记录查看和干预
- **职业规划管理**：规划数据总览与操作
- **学习资源管理**：资源库维护
- **题库管理**：题库 CRUD + AI 生成题目

### 实现细节

- **双层守卫**：`JwtAuthGuard`（身份认证）+ `RolesGuard`（角色为 `admin`）
- **数据看板**：聚合查询 5 个实体表的总数，按日期分组统计 7 天注册/创建趋势
- **管理粒度**：每个模块独立 CRUD 端点，支持分页和搜索
- **独立的 Vite 项目**：`admin-frontend/` 单独构建部署，端口 4177

## 十一、基础设施

### 功能概述

- **Prisma ORM**：数据库建模与迁移、可视化数据管理（Prisma Studio）
- **BullMQ 异步队列**：简历解析和报告生成的后台任务处理
- **Redis 缓存与限流**：内容缓存、会话管理、令牌黑名单、速率限制
- **全局异常处理**：统一错误格式，区分 Prisma 数据库错误和业务异常
- **全局响应拦截**：统一包裹 `{code, message, data}` 格式
- **参数校验**：全局 DTO 校验，自动剔除多余字段
- **邮件服务**：SMTP 邮件发送，开发环境自动回退到 Ethereal 伪造账号
- **Swagger 文档**：`/api-docs` 自动生成 API 文档，支持在线测试

### 实现细节

- **Prisma 异常映射**：`P2002`→409 冲突、`P2025`→404 不存在，其他→500
- **队列重试**：指数退避策略，1 分钟 → 5 分钟 → 15 分钟，最多 3 次
- **Redis 固定窗口限流**：通过 `@Throttle({limit, windowSeconds})` 装饰器配置，响应头返回 `X-RateLimit-*`
- **令牌黑名单**：退出登录或令牌刷新后将旧令牌加入 Redis 黑名单
- **自定义 JSON 解析器**：处理 `\uFEFF` BOM 头、控制字符等边缘情况
- **响应拦截器白名单**：通过 `__raw__` 标记跳过统一包裹，兼容文件下载等场景
