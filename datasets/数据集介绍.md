### 字段说明

该数据集涵盖完整的求职者画像信息，字段可分为以下几大类：

**个人信息与地址**

- `address` — 地址信息

**求职意向**

- `career_objective` — 职业目标/求职意向
- `job_position_name`（原名 `\ufeffjob_position_name`）— 应聘岗位名称

**技能与教育**

- `skills` — 技能列表（JSON数组格式）
- `educational_institution_name` — 教育机构名称
- `degree_names` — 学位名称
- `passing_years` — 毕业年份
- `educational_results` — 学业成绩
- `result_types` — 成绩类型（百分比/GPA等）
- `major_field_of_studies` — 专业领域

**工作经历**

- `professional_company_names` — 公司名称
- `company_urls` — 公司链接
- `start_dates` / `end_dates` — 起止时间
- `positions` — 职位名称
- `locations` — 工作地点
- `responsibilities` — 工作职责
- `related_skils_in_job` — 岗位相关技能

**课外活动**

- `extra_curricular_activity_types` — 活动类型
- `extra_curricular_organization_names` — 组织名称
- `extra_curricular_organization_links` — 组织链接
- `role_positions` — 担任角色

**语言与证书**

- `languages` — 语言能力
- `proficiency_levels` — 熟练程度
- `certification_providers` — 认证机构
- `certification_skills` — 认证技能
- `online_links` — 在线链接
- `issue_dates` / `expiry_dates` — 证书颁发/到期日期

**岗位要求与匹配度**

- `educationaL_requirements` — 学历要求
- `experiencere_requirement` — 经验要求
- `age_requirement` — 年龄要求
- `skills_required` — 岗位所需技能
- `matched_score` — **人岗匹配评分**（float，0~1）

## 2. Resume NER（中文简历命名实体识别数据集）

### 基本信息

| 项目 | 内容 |
|------|------|
| **名称** | Resume NER（简历命名实体识别） |
| **来源** | ModelScope / 阿里云（iic/resume_ner） |
| **许可证** | CC BY 4.0 |
| **下载链接** | <https://www.modelscope.cn/datasets/iic/resume_ner/summary> |
| **本地路径** | `datasets/resume_ner/iic/resume_ner/` |
| **下载脚本** | `datasets/download_resume_ner.py` |
| **分析脚本** | `datasets/analyze_resume_ner.py` |

### 数据规模

| 数据集 | 句子数 | 总标注数 |
|--------|--------|---------|
| **训练集** (`train.txt`) | **3,821 句** | 108,872 标注 |
| **验证集** (`dev.txt`) | **463 句** | 12,921 标注 |
| **测试集** (`test.txt`) | **477 句** | 13,274 标注 |
| **合计** | **4,761 句** | **135,067 标注** |

### 标注格式

采用标准的 **BIO（Beginning-Inside-Outside）** 标注格式（CoNLL 标准），每行一个"字 标签"对，空行分隔句子。

示例格式：

```
李 B-NAME
四 I-NAME
毕 O
业 O
于 O
北 B-ORG
京 I-ORG
大 I-ORG
学 I-ORG
```

### 实体类型

共标注 **8 种实体类型**：

| 实体类型 | 标签 | 说明 |
|---------|------|------|
| 人名 | `NAME` | 求职者姓名 |
| 地名 | `LOC` | 籍贯、所在地等地点信息 |
| 组织名 | `ORG` | 毕业院校、公司等组织机构 |
| 教育背景 | `EDU` | 学历信息（本科、硕士等） |
| 专业 | `PRO` | 所学专业名称 |
| 职称 | `TITLE` | 职位头衔、职称 |
| 国籍 | `CONT` | 国家/地区 |
| 民族 | `RACE` | 民族信息 |

### 实体分布统计

**训练集主要实体分布：**

| 实体类型 | B（起始） | I（内部） | 合计 |
|---------|----------|----------|------|
| CONT（国籍） | 1,948 | 790 | 2,738 |
| EDU（教育背景） | 2,225 | 286 | 2,511 |
| LOC（地名） | 5,023 | 3,130 | 8,153 |
| NAME（人名） | 3,821 | 8,889 | 12,710 |
| ORG（组织名） | 5,253 | 23,964 | 29,217 |
| PRO（专业） | 3,324 | 7,715 | 11,039 |
| RACE（民族） | 2,185 | 1,145 | 3,330 |
| TITLE（职称） | 5,649 | 8,018 | 13,667 |

### PDF 内容特征

每个 PDF 文件是一份完整的英文简历（原始格式），通常包含以下内容：

- **Summary** — 个人摘要/职业概览
- **Experience** — 工作经历
- **Education** — 教育背景
- **Skills** — 专业技能
- **Certifications** — 证书资质
- **Projects** — 项目经验

### 技术说明

- 使用 `datasets` 库加载时，`pdf` 字段返回的是 `pdfplumber.PDF` 对象（非原始 bytes）
- 本地存档通过从 HuggingFace 缓存复制原始 PDF 文件实现，无需网络即可访问
- 可使用 `pdfplumber` 直接读取 PDF 进行文本提取和分析

### 适用场景

- **简历文本解析** — 使用 pdfplumber/PyMuPDF 提取 PDF 文本
- **职业分类模型** — 基于简历内容进行职业分类（24类）
- **简历内容分析** — 不同行业简历的写作风格、关键词差异
- **AI 模拟面试** — 从简历提取技能和经验，生成个性化面试题
- **职业路径研究** — 分析不同职业的核心技能与经验要求
